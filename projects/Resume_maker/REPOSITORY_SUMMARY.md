## Overview
Resume_maker is a **CLI document generator** that turns structured JSON input into job-hunting documents — resume, cover letter, LinkedIn guide, and interview prep — as Markdown and PDF. It is Bun-first with **no framework dependencies**. It is the most personal-output-oriented project in the slice (it even ships sample inputs named after real people: `alexander-input.json`, `basil-input.json`).

## Technologies
- **Runtime:** Bun
- **Language:** TypeScript (strict)
- **Output:** Markdown + PDF (via `markdown-pdf`)
- **Quality:** ESLint, Prettier, markdownlint-cli2, cspell
- **Scripts (from `package.json`):** `build`/`start` (`bun index.ts`), `lint`, `lint:fix`, `lint:md`, `lint:spell`, `typecheck` (`bun tsc --noEmit`)
- **CLI flags (from AGENTS.md):** `--input`/`-i`, `--output`/`-o`, `--format`/`-f` (markdown, pdf, both)
- **Conventions:** `validateResumeData()` runs before processing; per-document generation isolated (one failure doesn't block others); PDF failure still saves Markdown; smoke test `scripts/smoke-resume.ts`; snapshot tests for Markdown output.

## Data Flow
1. User supplies JSON via `--input` (e.g. `alexander-input.json`).
2. `validateResumeData()` validates structure before any work proceeds.
3. Data is normalized, then per-document generators run in isolation (resume, cover letter, LinkedIn guide, interview prep).
4. Each document renders to Markdown; `markdown-pdf` converts to PDF where requested (`--format both`).
5. Outputs land in `output/`; a Markdown failure still yields a PDF-safe fallback and vice-versa.
