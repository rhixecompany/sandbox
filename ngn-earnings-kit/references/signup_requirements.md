# 🗂️ Signup Requirements — NGN Earnings Kit

Compiled from 8-category research (Aug 2026). Platform deep-dives live in `platforms/`.

## NGN payout rails (verified reality, Aug 2026)
| Rail | Status for Nigeria | Notes |
|------|--------------------|-------|
| **Payoneer** | ✅ BEST — works for NG | Free receiving account (USD/EUR/GBP); withdraw to any Nigerian bank in NGN (~1.2–2% + rate). uTest, Test.io, Testlio, Clickworker pay via Payoneer. |
| **PayPal (NG)** | ✅ Can RECEIVE | Nigerian PayPal accounts receive USD (NGN-held); withdraw to bank (~3.5% + spread). Most global panels (FreeCash, TimeBucks, Microworkers, TGM) support it. Some take extra fee (FreeCash 5%, Microworkers 7.5%). |
| **Wise** | ⚠️ caveats | Multi-currency OK; NG **receiving** pockets limited. Works for Mercor-like platforms; use for payouts, not a primary plan. |
| **Bank transfer (NGN)** | ✅ | SagaPoll (5,000 pts = ₦30k), PalmPay, Kuda, OPay — NGN-native apps. Fastest no-forex income. |
| **Airtime** | ⚠️ small | GeoPoll (~₦900/hr effective), Premise min ₦1,800. Not a cash beater. |
| **Crypto (BTC/USDT)** | ⚠️ | TimeBucks, FreeCash, Microworkers, SproutGigs. P2P conversion 1–3% in NG. ID check may be required. |
| **Gift cards** | ⚠️ | Amazon (rescind for NG at premium), CY.SEND (TGM $3 min). |
| **Wise** | ⚠️ | Works for Merck-like platforms; NG wallet receiving coverage limited. |

**Golden rule:** If a platform insists on ACH/paper checks only → it's US-only; skip.

## Common requirements by category

### AI Training / Data Annotation
- English + skills assessment (Math/Writing/Code) — strong writing + detail focus needed
- Location check (each platform verifies; Mercor official NG list ✅, DA likely, others vary)
- ID verification (passport, driver's license, NIN)
- Payment: PayPal / Payoneer / Wise (Merck; bank)
- Age 18+, internet + laptop
- **DataAnnotation:** 2.6% acceptance; PayPal primary.

### Surveys / Microtasks
- NGN phone for OTP (SagaPoll, TGM)
- Behavioral/demographic profile — keep truthful but "boring"; stay consistent across all panels
- PayPal link for USD GPTs (TimeBucks $3 min; FreeCash $5 PayPal)
- Some offer-wall tasks require app installs + screenshots

### User testing
- Desktop + mobile or both, screen-share comfortable, quiet space, decent mic
- Payoneer (uTest/TestIO/Testlio) or PayPal (Userlytics/Trymata/IntelliZoom)
- Profile + device list kept current (device inventory boosts invites)
- No screenshots of platforms that can't receive in NG (UserTesting, UserInterviews)

### Cashback / rewards
- Nigerian bank or NGN wallet (OPay, PalmPay, Kuda, Moniepoint)
- Some need BVN-linked KYC (Kuda Premium)

### Freelance / gigs
- Portfolio (site-supervisor references; construction/property projects)
- ID (NIN / driver's license); escrow contracts on Upwork/Fiverr
- Payoneer/Wise/PayPal + bank

### Mystery / field tasks
- Smartphone w/ camera + GPS; task app (SagaPoll, Premrise) or agency onboarding
- Appen: standard freelance signup + Payoneer

## First-week setup order (recommended)
1. **Payoneer** (free; needed by 5+ platforms)
2. **PayPal** NG (needed by TIME/FreeCash/Microworker + most)
3. Sign up uTead + Testlio + Test.io + Merck + TimeBucks
4. Add Saga & Premise for NGN-native rails
5. Link bank/Kuda for NGN payouts

## Common red flags on signup
- Asks for BVN + OTP, card PIN, or seed phrase → **LEAVE**
- "Activation fee", "training fee", "refundable deposit" → **SCAM**
- Request to verify with payment before withdraw → leave
- Referral caps far beyond market (e.g. "₦15k per friend" on unknown app) → suspicious
