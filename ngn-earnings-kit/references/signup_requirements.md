# 🗂️ Signup Requirements — NGN Earnings Kit

Compiled from research. Full details in each platform deep-dive under `platforms/`.

## Common requirements by category
### AI Training / Data Annotation
- English + (usually) skills assessment (Math/Writing/Code)
- Location check (many accept Nigeria; some don't — verify!)
- ID verification (passport, driver's license, NIN)
- Payment: PayPal / Payoneer / Wise (if platform supports NGN)
- Age 18+
- Internet + laptop

### Surveys / Microtasks
- NGN phone number for OTP
- Some require one active "tier" (paid app)
- Payoneer/PayPal/Wise for payout OR bank (NGN)
- Real camera for some face verification

### User testing
- Desktop / mobile + screen share OK
- Quiet space, decent mic
- Payment via PayPal / Wise

### Cashback / Receipt
- Nigerian bank account for transfer; some apps use Opay/PayPal

### Freelance/gig
- Portfolio (site supervisor references)
- ID verification (NIN / driver's license)
- Bank / escrow

## NGN payout methods — capability lookup
