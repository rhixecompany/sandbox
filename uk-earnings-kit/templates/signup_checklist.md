## TIER 1: DO THIS WEEK (Highest £/hr)

### 1. Prolific Academic Surveys
- [ ] Go to prolific.com → Join waitlist
- [ ] Install **Prolific Assistant** browser extension (Chrome/Firefox/Edge)
- [ ] Complete **ALL** "About You" profile sections (demographics = study eligibility)
- [ ] Bookmark dashboard.prolific.com
- [ ] Set notification sound in extension settings
- **Pay:** £8–15/hr | Min £6 PayPal | Instant–1 day

### 2. UserTesting
- [ ] Go to usertesting.com → "Get Paid to Test"
- [ ] Create account with verified PayPal email
- [ ] Complete **practice test** (desktop + mobile)
- [ ] Use good microphone (headset > laptop mic)
- [ ] Record in quiet room; think aloud CONSTANTLY
- [ ] Wait for approval email (24–72 hrs)
- **Pay:** £10/20-min test | Min £10 PayPal | 7 days

### 3. DataAnnotation.tech
- [ ] Go to dataannotation.tech → Sign up
- [ ] Complete qualification test (coding + English)
- [ ] Spend 30–45 mins on test — quality matters
- [ ] Wait for project invites (email + dashboard)
- [ ] Start with writing projects if coding test is hard
- **Pay:** £20–40/hr | Weekly Tue PayPal | No minimum

### 4. Matched Betting (Outplayed or OddsMonkey)
- [ ] Choose: Outplayed (£29.99/mo) or OddsMonkey (£24.99/mo)
- [ ] Sign up → Complete **all** training modules
- [ ] Open Smarkets/Betfair exchange account
- [ ] Open 3–5 bookmaker accounts (start with welcome offers)
- [ ] Do first welcome offer with calculator open
- [ ] Track every bet in their profit tracker
- **Pay:** £400–500 month 1 | £100–300/mo ongoing | Tax-free

### 5. Bank Switching Setup
- [ ] Open "burner" current account (Monzo/Starling/Chase — easiest)
- [ ] Set up 3 direct debits (Netflix, gym, phone, charity, etc.)
- [ ] Ensure £1,000+ pay-in (salary or manual transfer)
- [ ] Check MSE "Best Bank Switch Offers" table
- [ ] Initiate first switch via CASS (7 working days)
- **Pay:** £175–300/switch | 3–4×/year | Covered by PSA

### Email & Security
- [ ] Create dedicated email: `earnings@yourdomain` or `yourearnings@gmail.com`
- [ ] Enable 2FA on **every** platform

- [ ] Save recovery codes offline
