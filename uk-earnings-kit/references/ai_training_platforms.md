## Detailed Platform Breakdown

### 1. DataAnnotation.tech — The Gold Standard

- **Pay:** $20–40/hr (generalist), $30–50/hr (specialist/coding, finance, STEM)
- **Onboarding:** 1-3 hour qualification test, 10-20% acceptance rate
- **Payout:** Weekly (Tuesdays), PayPal, no minimum
- **Tasks:** RLHF ranking, code evaluation, creative writing, fact-checking
- **Pros:** Clean interface, reliable pay, diverse task types
- **Cons:** Sporadic communication from team, can have dry spells, waitlist sometimes active
- **UK Status:** Open — apply now

### 2. Mercor — Fastest Onboarding, Highest Potential

- **Pay:** $40–150/hr (varies by role)
- **Onboarding:** 1-3 days, interview-based
- **Payout:** Weekly via PayPal
- **Tasks:** AI model training, code evaluation, domain-specific review
- **Pros:** AI-powered matching pairs you to projects, fastest path to high-paying work
- **Cons:** Tracking software (Insightful) — consider a dedicated work device
- **UK Status:** Open — actively recruiting UK-based experts

### 3. Alignerr (Labelbox) — The New Contender

- **Pay:** $20–50/hr
- **Onboarding:** Assessment-based, relatively fast
- **Payout:** Bi-weekly
- **Tasks:** Data annotation, model evaluation, RLHF
- **Pros:** Modern workflow, newer platform = less competition currently
- **Cons:** Still scaling, task volume can be inconsistent
- **UK Status:** Accepting UK applicants

### 4. Invisible Technologies — Stable Long-Term Projects

- **Pay:** $25–100/hr
- **Onboarding:** Multi-stage interview, structured
- **Payout:** Weekly, via Hubstaff tracking
- **Tasks:** AI operations, data review, content operations, team-based projects
- **Pros:** Long-term projects (not one-off tasks), team environment
- **Cons:** Hubstaff time tracking, structured hours
- **UK Status:** Remote, UK-friendly

### 5. Braintrust — Premium Client Base

- **Pay:** $40–150/hr
- **Onboarding:** Portfolio/application review
- **Payout:** Bi-weekly
- **Tasks:** AI training, software engineering, domain expertise
- **Pros:** Premium clients, high rates, flexible
- **Cons:** Selective — requires strong portfolio
- **UK Status:** Open

### 6. Turing — Engineering-Focused Contracts

- **Pay:** $25–100/hr
- **Onboarding:** 3-7 days, tech assessment
- **Payout:** Bi-weekly
- **Tasks:** Software engineering AI training, code evaluation
- **Pros:** Stable long-term contracts, best for engineers
- **Cons:** Engineering-heavy, less variety in tasks
- **UK Status:** Open

### 7. Handshake AI / Micro1 — Domain Expert Focus

- **Pay:** $20–100/hr (domain-dependent)
- **Onboarding:** Automated AI interviewer ("Zara") for instant onboarding
- **Payout:** Weekly
- **Tasks:** Domain expert review (finance, law, medicine, coding)
- **Pros:** Fast onboarding via AI interview, domain expertise pays premium
- **Cons:** Narrower task range — you need specific expertise
- **UK Status:** Accepting UK experts

### 8. OpenTrain AI — Aggregator Model

- **Pay:** $20–50/hr
- **Onboarding:** Per-provider assessment
- **Payout:** Varies by provider
- **Tasks:** Mathematics, STEM, text annotation, code training
- **Pros:** Aggregates tasks from multiple AI labs, steadier volume
- **Cons:** Variable pay across providers, fragmented dashboard
- **UK Status:** Open

### 9. OneForma — Low Barrier Entry

- **Pay:** $10–30/hr
- **Onboarding:** Simple registration, per-project training
- **Payout:** Monthly, PayPal/Wise
- **Tasks:** Transcription, translation, linguistic evaluation, data collection
- **Pros:** Easy to start, multilingual projects, global
- **Cons:** Lower pay ceiling, payments can be slow
- **UK Status:** Open globally

### 10. CrowdGen (Appen) — Beginner-Friendly

- **Pay:** $10–25/hr
- **Onboarding:** Simple, fast
- **Payout:** Weekly via PayPal
- **Tasks:** Data annotation, search evaluation, content moderation
- **Pros:** Consistent beginner tasks, easy onboarding
- **Cons:** Lower pay, repetitive tasks, 1.3/5 Trustpilot rating (frustration with management)
- **UK Status:** Open

## Stacking Strategy

The real advantage of AI training work is **stacking platforms**:

```
Morning:   Check DataAnnotation + Mercor for tasks (~15 min)
Daytime:   Work on whichever has active tasks
Evening:   Check Alignerr + OpenTrain for overflow
Weekly:    Cash out from all — spread risk
```

When one platform is slow, move to another. No meetings, no clients, no selling. A browser and good written English is all you need.

## Red Flags

- **Impersonation scams** — No legitimate platform asks for payment or banking passwords during application
- **Unpaid assessments** — DataAnnotation's 1-3hr assessment is unpaid but typical; anything longer is suspect
- **"Pay for certification/training"** — Real platforms assess for free
- **Region-tiered pay** — Outlier, Mindrift, and Meridial pay less in some regions (UK is usually mid-tier)
- **Tracking software** — Mercor uses Insightful, Invisible uses Hubstaff — use a dedicated work device if concerned
