# UK Tax Return Snippet — Side Earnings

## Example: Self-Assessment (SA100) for 2025/26 Tax Year

This sample shows how to report £4,500 in side earnings alongside a full-time job.

---

## Key Information

| Field               | Value                             |
| ------------------- | --------------------------------- |
| **Tax Year**        | 2025/26 (6 Apr 2025 – 5 Apr 2026) |
| **Main Job Salary** | £35,000                           |
| **Side Earnings**   | £4,500                            |
| **Expenses**        | £500 (laptop, software, internet) |
| **Tax Reference**   | Self Assessment (SA100)           |
| **Deadline**        | 31 Jan 2027 (online filing)       |

---

## HMRC SA100 — Relevant Sections

### SA103S (Short Self-Employment Pages)

**Box 4:** Your turnover (total side earnings)
→ **£4,500**

**Box 7:** Allowable business expenses
→ **£500** (see expense breakdown below)

**Box 10:** Total net profit (Box 4 — Box 7)
→ **£4,000**

**Box 12:** If your turnover was under £1,000 you can use the trading allowance instead
→ **N/A** (turnover over £1,000)

### Trading Allowance Calculation

| Method                | Calculation     | Taxable Profit |
| --------------------- | --------------- | -------------- |
| **Actual expenses**   | £4,500 - £500   | £4,000         |
| **Trading allowance** | £4,500 - £1,000 | £3,500         |

**Best choice:** Trading allowance (£3,500 taxable) — saves £100 vs actual expenses.
_Re-evaluate annually — if expenses exceed £1,000, use actual expenses instead._

## Tax Calculation

| Description                           | Amount                            |
| ------------------------------------- | --------------------------------- |
| Main job salary                       | £35,000                           |
| Side earnings profit                  | £3,500 (trading allowance method) |
| **Total income**                      | **£38,500**                       |
| Personal allowance (2025/26: £12,570) | -£12,570                          |
| **Taxable income**                    | **£25,930**                       |
| Basic rate (20% on £25,930)           | £5,186                            |
| **Class 2 NIC** (if profit > £6,725)  | N/A (under threshold)             |
| **Class 4 NIC** (if profit > £12,570) | N/A (under threshold)             |
| **Total tax due**                     | **£5,186**                        |

> **Note:** The tax is spread across your total income, not charged twice on side earnings. The personal allowance and tax bands cover all income combined.

## Additional Notes

### When You Need to Register

| Situation              | Must Register? | Deadline                 |
| ---------------------- | -------------- | ------------------------ |
| Side earnings < £1,000 | No             | N/A                      |
| Side earnings > £1,000 | Yes            | 5 Oct 2026 (for 2025/26) |
| Main job only          | No             | N/A                      |

### How to Register

1. Go to [gov.uk/register-for-self-assessment](https://www.gov.uk/register-for-self-assessment)
2. Click "Register if you're self-employed"
3. Get your Unique Taxpayer Reference (UTR) in 10 working days
4. File online by 31 Jan 2027
