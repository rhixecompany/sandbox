# Referral Message Templates

Use these templates when referring friends to earning platforms. Many platforms offer £5-25 per successful referral.

---

## Social Media / Group Chat

### Short Version (WhatsApp / SMS)

> "Been using [Platform] to earn extra cash — made £XX so far. If you sign up with my link we both get a bonus. No catch, just free money for existing: [link]"

### Medium Version (Facebook / Discord)

> "Anyone looking to earn a bit extra? I've been using [Platform] and it's legit — made £XX in the last [timeframe]. UK-friendly, pays via PayPal/bank transfer. Use my referral link and we both get £XX bonus: [link]"

### Detailed Version (Reddit / Forum)

> **Quick tip:** [Platform] is currently offering a £XX signup bonus for UK users. I've been using it for [timeframe] and cashed out £XX so far. Easy to use, reliable payouts.
>
> Non-ref link: [URL]
> Ref link (we both get £XX): [URL]

## Best Practices

| Do | Don't |
|----|-------|
| Mention how much you've actually earned | Lie about earnings or make wild claims |
| Say it's UK-friendly | Post in non-UK groups |
| Include non-ref link for trust | Only share referral links |
| Be honest about requirements | Claim it's "zero effort" |
| Post in relevant communities | Spam the same message everywhere |

---

## Ethical Rules

1. **Always disclose referral links** — "Full disclosure: this is my referral link, we both get a bonus"
2. **Only refer platforms you actually use** — Don't promote scams
3. **Don't spam** — Share where it's relevant and welcome
4. **Be accurate** — Don't exaggerate earnings potential
5. **No fake reviews** — Don't post fake Trustpilot/Reddit reviews
