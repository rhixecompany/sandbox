## Docker Cleanup Plan
Your system has **913.8MB of unused images** and minimal other overhead. Here's the cleanup sequence:
### 1. **Unused Images** (Reclaim 913.7MB)
```powershell
# Remove all unused images
docker image prune -a --force
```
- Removes dangling images (orphaned layers)
- `-a` flag removes ALL unused images, not just dangling ones
- `-f` skips confirmation
### 2. **Unused Containers** (Your system: 0 unused)
```powershell
docker container prune --force
```
- Removes all stopped containers
- Safe if no container state needs preservation
### 3. **Unused Volumes** (Your system: 0 unused)
```powershell
docker volume prune --force
```
- Removes local volumes not mounted to any container
- ⚠️ Data loss risk — verify no important volumes first
### 4. **Build Cache** (Your system: 0 unused)
```powershell
docker builder prune --all --force
```
- Clears build cache, forcing full rebuilds on next `docker build`
- Reclaims space but slows subsequent builds
### 5. **Models** (Docker Model Runner)
```powershell
# List loaded models
docker model ls
# Remove specific model
docker model rm <model-name>
# Or prune all unused models
docker model prune
```
- Only applicable if you use Docker Model Runner
- Check `docker model ls` first; if empty, skip this
### 6. **MCP Toolkit**
MCP Toolkit is a **configuration feature in Docker Desktop**, not a storage artifact:
- Managed in **Docker Desktop settings** → MCP section
- Disable unused MCP servers in settings (no disk cleanup needed)
- Cached MCP data lives in `%LOCALAPPDATA%\Docker\mcp\` — safe to delete if you've disabled all MCP servers

## Quick Nuclear Option
```powershell
# Remove everything unused in one command
docker system prune -a --volumes --force
```
- Removes all unused images, containers, volumes, and networks
- ⚠️ Does NOT affect build cache or models
