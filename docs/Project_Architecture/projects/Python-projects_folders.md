## Key Patterns

- **Flat structure:** No subdirectories — all scripts are peers
- **Descriptive snake_case** for filenames
- **Single-file scripts:** Each `.py` file is self-contained
- **Categories:** Games, utilities, algorithms, finance, image processing, security, networking
