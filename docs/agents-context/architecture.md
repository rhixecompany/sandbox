# SandBox — Architecture Blueprint

> Generated by agents-system-prompt-context-fix | 29 subprojects with `.vscode/`

## Overview

SandBox is a monorepo-style workspace hosting **29 subprojects** plus root automation tooling
(prompt assets, Hermes plans, audit reports). It mixes TypeScript/Bun tooling, Python data scripts,
Django web apps, and a multi-language MCP-server collection.

## Root

- **Language/runtime:** Bun (TypeScript) + Python 3.11/3.13 (venv)
- **Build/typecheck:** `bun run build`, `tsconfig.json` (strict, bundler resolution)
- **Key dirs:** `prompts/`, `templates/`, `.github/`, `.hermes/`, `docs/`, `projects/`, `results/`

## Subproject Categories

- **MCP servers** (0): `projects/mcp-servers/<lang>/` — TypeScript, Python, Go, Rust, Java, Kotlin, PHP, Ruby, Swift, C#, copilot-studio
- **Python** (4): standalone scripts & Django/Scrapy/Selenium apps
- **Web/TS** (6): Bun/TypeScript + Next.js e-commerce, resume maker, downloaders
- **Comics** (3): comicwise, rhixecompany-comics, rhixe_scans (Supabase)
- **Other** (16): Banking, docs, profile, Django-Scrapy-Selenium

## Cross-Cutting Concerns

- Single root `.vscode/` with shared launch/tasks/settings; each subproject overrides.
- Shared conventions in root `AGENTS.md` / `SOUL.md` (Bun, PowerShell, git, DRY, scoped edits).
- Hermes profiles & plans under `.hermes/`; ecosystem audit plan tracked.
