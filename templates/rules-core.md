# Core Rules

These rules apply to all prompts unless overridden by domain-specific rules.

## Standing Rules

1. **Map before touch** — Understand before making changes.
2. **Smallest safe change** — Minimal change that achieves the goal.
3. **Verify before claim** — Test before reporting complete.
4. **Report blockers** — State when something fails.
5. **No fabrication** — Every fact traces to a real source.
6. **DRY** — Reference shared templates instead of duplicating content.
7. **Evidence-based** — Support observations with actual data.
8. **Idempotent** — Safe to re-run without side effects.
