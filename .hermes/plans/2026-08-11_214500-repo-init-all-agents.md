# Repo Init Kit for All Installed AI Agents

## Goal

Deliver a reusable kit (`skills`, `scripts`, `plan`, `prompt`, `hooks`) that lets any new or existing repo initialize context for **all installed AI agents** on this machine, plus a complete inventory listing every installed agent and where its system prompt and context files live.

## Proposed Approach

Runtime-detected, idempotent, no-destroy:

1. **`scripts/repo-init.py`** — single entry point:
   - `--list-agents`: detect installed agents (Hermes, OpenCode, Codex, Copilot, Claude, Cursor, gh) and print each agent's binary/profile + system prompt path + context file path (live filesystem probing, not hardcoded).
   - `--init [dir]`: scaffold a repo for every detected agent — copy/symlink context templates (AGENTS.md, CLAUDE.md, .cursorrules, .github/agents/README, opencode.json, .codex/agents/README) into the target dir. Idempotent: skip existing files unless `--force`.
   - `--verify [dir]`: check the scaffolded files resolve against live agent roots; exit non-zero with a report on mismatch.
2. **`docs/ai-agents-inventory.md`** — the listing deliverable: every installed agent + system prompt + context file (regenerated by `--list-agents --json > docs/...`).
3. **Skill `repo-init`** (class-level, `scripts/` + `SKILL.md`) — wraps the script: trigger when user wants to init a repo for all AI agents.
4. **Prompt `repo-init.prompt.md`** under `.github/prompts/` — slash-command prompt that runs the script + verification.
5. **Hook** — optional `post-clone` style hook entry (documented in `.github/hooks/README.md` section) that calls `repo-init.py --init` on repo entry; wired via existing hooks lib.

## Risks / Tradeoffs

- Agent detection depends on live filesystem state; paths may drift. Mitigation: script probes every run; inventory doc marks "as of" date.
- Copying agent context into a repo can leak environment specifics — templates are generic, never include secrets or absolute user paths in committed files.
- `.github/agents/` already has 30 real agents in this workspace — `--init` must NOT overwrite them (idempotent skip).
- Hermes root `USER.md`/`MEMORY.md` live in `memories/`, not root — script must probe, not assume.
